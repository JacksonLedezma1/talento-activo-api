# Talento Activo - Full Stack Project 🚀

Este repositorio contiene tanto el backend (API) como el frontend (Web) del proyecto Talento Activo.

## 📁 Estructura del Proyecto

- **/backend**: API robusta construida con NestJS, TypeORM y PostgreSQL.
- **/frontend**: Aplicación web moderna construida con React, Vite y Tailwind CSS.

## 🚀 Cómo empezar

### Backend
1. Entra a la carpeta `backend`.
2. Instala dependencias: `npm install`.
3. Configura el `.env`.
4. Ejecuta: `npm run start:dev`.

### Frontend
1. Entra a la carpeta `frontend`.
2. Instala dependencias: `npm install`.
3. Ejecuta: `npm run dev`.

---
Consulte los archivos README individuales dentro de cada carpeta para obtener instrucciones más detalladas.
